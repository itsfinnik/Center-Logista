# Форматы CSV файлов для загрузки

## Минимальный формат (только адреса)

Для работы системы **достаточно только колонки с адресами**. Все остальные поля заполнятся автоматически.

### Пример: `example_simple.csv`
```csv
Адрес
г. Ростов-на-Дону, ул. Большая Садовая, 115
г. Ростов-на-Дону, пр. Буденновский, 93
г. Ростов-на-Дону, ул. Пушкинская, 10
```

**Поддерживаемые названия колонки с адресами:**
- `Адрес`
- `Адрес объекта`
- `Address`
- Любое название, содержащее слово "адрес" или "address"

---

## Расширенный формат (с дополнительными полями)

Вы можете добавить дополнительные колонки для более точной настройки:

### Пример: `example_extended.csv`
```csv
Адрес,Уровень клиента,Время начала рабочего дня,Время окончания рабочего дня
г. Ростов-на-Дону, ул. Большая Садовая, 115,VIP,09:00,18:00
г. Ростов-на-Дону, пр. Буденновский, 93,Standart,08:30,17:30
```

### Опциональные колонки:

| Колонка | Возможные названия | Значение по умолчанию | Формат |
|---------|-------------------|----------------------|---------|
| **Номер объекта** | `Номер объекта` | Автоматическая нумерация | Целое число |
| **Координаты** | `Географическая широта`, `Широта`, `Latitude` | Автогеокодирование | Число с плавающей точкой |
| | `Географическая долгота`, `Долгота`, `Longitude` | | |
| **Время работы** | `Время начала рабочего дня` | 09:00 | HH:MM |
| | `Время окончания рабочего дня` | 18:00 | HH:MM |
| **Обед** | `Время начала обеда` | 13:00 | HH:MM |
| | `Время окончания обеда` | 14:00 | HH:MM |
| **Приоритет** | `Уровень клиента` | Standart | VIP или Standart |

Полный формат включает все возможные поля:

```csv

2,"344002, г. Ростов-на-Дону, пр. Сиверса, д. 90",47.177319,39.73957,08:30,18:00,12:30,13:30,VIP
```

## Важные моменты

1. **Обязательна только колонка с адресами**  
   Система автоматически заполнит остальные поля значениями по умолчанию.

2. **Автогеокодирование**  
   Если координаты не указаны, система автоматически определит их по адресу на клиенте.

3. **Гибкое распознавание**  
   Система распознает различные варианты названий колонок (рус/англ).

4. **Формат адреса**  
   Рекомендуется указывать полный адрес: "г. Ростов-на-Дону, ул. Название, д. X"

5. **Размер файла**  
   Максимальный размер файла: 5 МБ

---

## Примеры файлов в проекте

- `test_data.csv` - полный формат со всеми полями (100 адресов)
- `example_simple.csv` - минимальный формат (только адреса, 10 шт.)
- `example_extended.csv` - расширенный формат (адреса + VIP + время работы, 10 шт.)

---

## Использование

1. Откройте http://localhost:8000/static/app.html
2. Нажмите "Выберите CSV файл"
3. Выберите ваш CSV файл
4. Система автоматически обработает и отобразит адреса на карте
