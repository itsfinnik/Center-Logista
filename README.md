## 📋 Описание

Интеллектуальная система планирования выездов для предпринимателей, которая автоматически оптимизирует маршруты посещения клиентов с учетом:

- ⏰ Временных окон работы клиентов
- 🍽️ Обеденных перерывов
- ⭐ VIP-приоритетов
- 🚗 Реального времени в пути
- 📍 Точного геокодирования адресов

## 📊 Алгоритм оптимизации

### Умная приоритизация VIP-клиентов

```python
if (2+ обычных клиента ближе стартовой точки, чем VIP):
    начать с ближайшего обычного клиента
else:
    начать с VIP-клиента
```

### Многокритериальная оценка

Для каждого следующего клиента вычисляется:

```
Оценка = Расстояние + Штраф_за_время + Бонус_за_VIP
```

Где:
- **Расстояние**: по формуле Haversine
- **Штраф за время**: при опоздании или раннем приходе
- **Бонус за VIP**: удвоенный вес для VIP-клиентов
